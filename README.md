# 岁岁 · 时光纪念馆 (`Suisui-Backup`)

> **岁岁可以年年。**  
> 在彻底说再见之前，把这里写过的字、拍过的照、录过的声音，原封不动带回家。

- **在线纪念馆地址**：<https://岁岁年年.life>
- **开源仓库地址**：<https://github.com/Map0u/Suisui-Backup>

---

## 一、这个工具能帮你保存什么？

本工具用于协助岁友在服务关停前，将属于自己的历史记录一次性完整导出为本地 `.zip` 备份包，并在 1:1 还原的原版「岁岁」五栏界面（树洞、解忧、心情、互动、我的）中离线翻看：

- **树洞动态**：全部树洞文字、高清配图原图、每一段 `.wav` 原声语音录音、专属信纸背景与置顶标记。
- **完整评论区**：每条树洞下的全部历史评论与楼中楼回复（自动翻页拉齐，包含评论者头像、`Lv` 等级、IP 属地、时间、点赞数与评论配图）。
- **解忧杂货铺与不晚邮局**：寄出的信、往来回信、抬头称呼与博物馆馆藏印章。
- **时空未来信**：写给未来的信、约定开启日期以及附带的照片与音频。
- **心情与碎碎念日记**：心情打卡记录、情绪原因描述、情绪统计报告，以及带配图的碎碎念日记。
- **个人主页与岁友足迹**：个人资料、主页背景图、头像框、主页音乐、性格标签、加入天数印章，以及关注、粉丝、访客列表与心愿电台。

## 二、怎么把回忆存下来？

> **核心提示**：**所有端（电脑网页 / 安卓 App / 安卓网页 / 苹果网页）**都可以直接用岁岁手机号+密码登录自动拉取，并一键导出 `.zip` 压缩包保存。  
> **多副本保存原则**：导出的 `.zip` 压缩包请务必在电脑硬盘或个人网盘妥善保存一份。电脑端解压双击《打开岁岁纪念馆.html》或用记事本打开《岁岁记忆全文合集.txt》属于开放标准文件，即使十年后也能稳定查阅。

### 方式 A：直接使用在线网页（电脑 / 安卓 / 苹果浏览器免安装）

1. 用电脑或手机浏览器打开 **<https://岁岁年年.life>**。
2. 输入你的岁岁手机号与密码登录（注：由于近期岁岁官方第三方短信通道已欠费停发，手机可能收不到验证码，请直接使用**密码登录**）。
3. 等待几秒至几十秒，页面会自动拉齐你的全部树洞、配图原图、原声语音、评论楼中楼、信件、心情与日记。
4. 点击顶部橙色按钮 **「保存全部岁岁回忆」**，即可将完整的 `.zip` 纪念馆压缩包保存到本地。
   - **苹果用户注意**：Safari 导出时请务必立刻点击「存储到文件」并转存至电脑或个人网盘。

### 方式 B：使用安卓独立 App（`岁岁纪念馆.apk`）

1. 在纪念馆网页或本仓库 [`public/download/suisui-memorial.apk`](./public/download/suisui-memorial.apk) 下载安装 **「岁岁纪念馆.apk」**。
2. 打开 App，既可以直接在 App 内输入手机号+密码登录自动拉取并导出 `.zip` 压缩包（拉取后会自动保存在 App 内供离线随时翻看），也可以直接点击导入已有的 `.zip` 压缩包。
3. **特别提醒**：未来安卓系统大版本升级未必长期兼容旧版 APK，**请务必把导出的 `.zip` 压缩包在电脑或网盘存一份**。

### 方式 C：下载本仓库到电脑上单机运行（零依赖开箱即用）

本项目服务端 100% 使用 Node.js 原生内置模块编写，**无需执行 `npm install` 安装任何第三方依赖**：

1. 在电脑上安装 [Node.js](https://nodejs.org/)（建议 v18 及以上版本）。
2. 点击本页面右上角绿色 `Code` -> `Download ZIP` 下载源码并解压（或执行 `git clone https://github.com/Map0u/Suisui-Backup.git`）。
3. **启动服务**：
   - **Windows 电脑**：直接双击根目录下的 **`启动岁岁纪念馆.bat`**，会自动启动服务并打开浏览器 `http://127.0.0.1:3566`。
   - **macOS / Linux**：在终端进入本目录，运行 `bash start.sh`（或 `node server/index.js`），然后用浏览器打开 `http://127.0.0.1:3566`。

## 三、以后岁岁停服了，怎么翻看下载好的备份包？

导出的 `.zip` 压缩包内包含四样文件：
- `打开岁岁纪念馆.html` —— 双击即可在电脑浏览器离线浏览的独立网页（1:1 还原原版五栏体验）
- `岁岁记忆全文合集.txt` / `.md` —— 按时间排好版的纯文字手账（含全部树洞正文、评论楼中楼、日记与信件），任何记事本都能直接打开
- `media/` 文件夹 —— 所有的照片原图（`.jpeg`/`.png`）、评论头像与原声语音文件（`.wav`）
- `data/archive.json` —— 完整原始结构化归档数据

### 1. 电脑端查看（Windows / Mac · 最稳妥 · 永久兼容）
- **方法一（免解压还原完整界面）**：打开在线网页或本地启动的 `http://127.0.0.1:3566`，点击首页底部的 **「直接打开已保存的岁岁备份包」**，选中你的 `.zip` 文件，即可免解压还原完整的五栏岁岁界面。
- **方法二（解压双击离线网页）**：将 `.zip` 完整解压到电脑任意文件夹，直接双击里面的 **`打开岁岁纪念馆.html`**，断网也能看照片、翻评论、听当时的语音。
- **方法三（记事本阅读手账）**：直接打开 **`岁岁记忆全文合集.txt`**，所有文字、心情与信件一目了然。

### 2. 安卓手机查看（`岁岁纪念馆.apk`）
- 既可以直接在 App 内登录账号自动拉取并导出 `.zip` 压缩包（同时自动保存在 App 内供离线翻看），也可以直接导入已有的 `.zip` 压缩包。
- 该安装包**不申请任何联网权限（0 权限）**，完全在手机本地离线运行。
- **重要提醒**：未来安卓系统大版本升级未必长期兼容，**请务必把 `.zip` 压缩包在电脑或网盘存一份**。

### 3. 苹果手机查看（iOS / Safari / 文件 App）
- 苹果系统无法安装离线 App，且 Safari 浏览器缓存随时可能被系统清理或换机丢失，**不能指望浏览器缓存长期保存数据**。
- 苹果用户在网页导出 `.zip` 压缩包后，**请务必立刻点击「存储到文件」并转存到电脑或个人网盘**。
- 平时翻看方式：
  1. 可在 Safari 打开网页，点击首页 **「直接打开已保存的岁岁备份包」** 选中本机存好的 `.zip` 临时免解压预览。
  2. 或在系统自带 **「文件」App** 中直接解压 `.zip`，进入 `media/` 文件夹查看照片与语音，或直接点击打开 `岁岁记忆全文合集.txt` 阅读纯文字手账。
